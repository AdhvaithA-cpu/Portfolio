# Passenger Communication in U.S. Aviation

**Author:** Adhvaith Ananth  
**Context:** Institute for Youth in Policy fellowship capstone

The brief examines fragmented passenger information across airlines, airports, and security agencies. The legislative proposal describes consistent communication categories, accessible guidance, security preparedness, and a three-year airport pilot.
